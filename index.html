Projects

FinSight

Final-year project, in progress · Code

FinSight answers questions about financial-report pages using open LLMs.

The LLM never does the arithmetic. It writes the calculation, a safe Python executor runs it, and FinSight checks that every number appears on the page.

Each answer comes back with its unit, its calculation and the source rows highlighted.

I evaluate it with the official TAT-DQA scorer, and I've designed a user study to test whether seeing the evidence changes trust.

FinShield

Solo project · React, Express, MCP

FinShield spots stale subscriptions and hidden bank fees, judges whether income is stable, and writes a step-by-step plan for a simulated money crisis.

It runs as a web app with chat and a live dashboard, and as an MCP server with 14 tools that plugs into Claude Desktop.

Nothing gets cancelled or flagged without approval. It runs on mock data for now.
